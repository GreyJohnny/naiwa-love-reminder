# 奶蛙 / 牛来的爱意提醒物语 🐸🐮💛

一款提醒你喝水、远眺、伸展的小软件：在设定的时间范围内，每隔一段时间就弹出一只捧腹大笑的奶蛙，或一车赶来提醒你的牛来，配上魔性音效，让小习惯不再被忘记。到结束时间自动停止，第二天到点继续。

仓库包含 **macOS 奶蛙原版、Windows 奶蛙版和 Windows 牛来版**，按你的系统和喜欢的形象选择即可。

## 为什么写这个软件

是这样的，我发现我的学习以及工作可能长期接触电脑屏幕，有点担心我的眼睛安全（视力下降+干涩），于是就上网学了点护眼的小方法，这种一般都是几十分钟就做一次的，做这个就相当于我在我的主线程之外又加了个小线程来盯着我做，那我老是会忘记做，如果用手机闹钟提醒呢，要自己再重新点一遍（不是无限循环），同时呢，我还可以多做几个提醒来伸一伸腰啊、站一站，于是我就根据这个需求 vibe 了这么一个提醒我的软件。

## 功能特性

- ⏰ **自定义间隔**：每隔 N 秒 / 分钟 / 小时提醒一次，无限循环，不用像手机闹钟那样每次重新点
- 🏷️ **标签说明**：每个提醒写上一句话（"喝水""远眺 20 秒""伸个懒腰"），弹窗时大字显示
- 📚 **多个并行**：想开几个开几个，每个提醒独立倒计时、互不影响
- 📅 **时间范围**：每个提醒都有生效时间段（支持跨午夜，如 22:00 ~ 02:00），范围内循环提醒，**过了结束时间自动停止**，第二天到点自动恢复
- 🐸 **魔性弹窗**：提醒时弹窗浮在所有窗口之上，奶蛙大图快速轮播 + 摇摆动画 + 放声大笑，下面写着你的标签
- 🔕 **后台常驻**：关掉主窗口 App 不退出，在后台继续盯着你；菜单栏有小奶蛙图标随时召唤
- 💾 **数据持久**：提醒列表保存在本地，重启 App、重启电脑都不丢
- ⏸️ **随开随关**：每个提醒都可以暂停 / 继续 / 删除，还有"测试"按钮立即预览效果

## 界面一览

主窗口上半部分是一个大字时钟，中间是新建提醒的表单（标签 + 间隔 + 时间范围），下面是提醒列表。提醒触发时，屏幕中央弹出白色圆角卡片：一只捧腹大笑的奶蛙 + 你的标签 + 「知道啦 😄」按钮，20 秒无操作自动关闭。

## 牛来 Windows 版

**牛来的爱意提醒物语 🐮💛** 是奶蛙 Windows 版的牛来皮肤版本，使用 **Python 3 + PySide6（Qt 6）** 实现。把要做的事交给牛来：时间一到，一车牛来就从屏幕中央弹出来提醒你。

![牛来提醒动图](niulai-windows/assets/niulaigif.gif)

### 牛来有什么特别的

- 🐮 **牛来动图**：提醒弹窗播放牛来 GIF，叠加摇摆动画，并显示你的提醒标签。
- 🔊 **两种音效**：弹窗播放提醒音效，点击「＋ 添加提醒」或「知道啦」会响一声「牛来」；支持音量调节和试听。
- ⏰ **定时循环提醒**：支持秒 / 分钟 / 小时、多条提醒并行、每天的生效时间范围，以及跨午夜时段。
- ✏️ **随时调整**：每条提醒可以编辑、测试、暂停 / 继续；删除前会确认。
- 🔕 **托盘常驻**：关闭主窗口时可选择「直接关闭」或「程序最小化」，也可以记住选择；最小化后继续提醒，从托盘图标唤回主窗口。
- 💾 **本地保存**：提醒和音量设置保存在本机，重启程序后仍然保留。

弹窗可以点击图片或「知道啦」关闭，20 秒无操作也会自动关闭。

### 从源码运行

需要 **Windows 10 / 11、Python 3.10+**。先下载本仓库并解压，进入 `niulai-windows` 文件夹；也可以使用 Git：

```powershell
git clone https://github.com/GreyJohnny/naiwa-love-reminder.git
cd naiwa-love-reminder\niulai-windows
```

在该文件夹中安装依赖，然后启动：

```powershell
python -m pip install PySide6
.\run.bat
```

安装好依赖后，日常使用直接双击 `run.bat` 即可，它会通过 `pythonw.exe` 启动，不显示命令行黑框。也可以运行 `pythonw app\niulai_app.py`。

### 打包成免安装 EXE

在 `niulai-windows` 文件夹中执行：

```powershell
python -m pip install PySide6 pyinstaller
powershell -ExecutionPolicy Bypass -File build.ps1
```

打包后双击 `dist\NiulaiReminder\NiulaiReminder.exe` 即可使用，运行打包版无需另外安装 Python。**复制或移动时请保留整个 `NiulaiReminder` 文件夹，包括 `_internal`，不要只复制 EXE。**

### 开始使用

1. 输入提醒内容，例如「喝水」「站起来活动」「远眺 20 秒」。
2. 设置提醒间隔和每天的生效时间范围，点击「＋ 添加提醒」。
3. 点击提醒旁的「测试」查看弹窗并播放音效。
4. 想后台持续提醒，关闭窗口时选择「程序最小化」；彻底退出时，右键托盘图标选择「退出牛来提醒」。

Windows 11 可能把托盘图标放在任务栏的隐藏图标区域。想开机自动运行，按 `Win+R` 输入 `shell:startup`，将 EXE 的快捷方式放入启动文件夹。

提醒数据：`%APPDATA%\NiulaiReminder\reminders.json`；音量和关闭窗口的偏好：`%APPDATA%\NiulaiReminder\settings.json`。

更多操作、与奶蛙版的差异和已知限制，见 [牛来 Windows 版完整说明](niulai-windows/README.md)。

## macOS 使用说明

### 下载即用（推荐）

1. 从 [Releases](../../releases) 下载 `奶蛙的爱意提醒物语.zip`，解压
2. 把 `奶蛙的爱意提醒物语.app` 拖到「应用程序」文件夹（或任何你喜欢的位置）
3. 双击打开。因为 App 没有 Apple 开发者签名，首次打开如果提示"无法验证开发者"，请：
   - 右键点 App →「打开」→ 再点「打开」；或
   - 系统设置 → 隐私与安全性 → 找到被拦截的 App →「仍要打开」
4. 想开机自动提醒：系统设置 → 通用 → 登录项 → 添加本 App

### 添加一个提醒

1. 「提醒我干嘛」里写标签，比如 `喝水`、`站起来活动`、`远眺 20 秒`
2. 设置间隔：数字 + 单位（秒 / 分钟 / 小时），比如 `30 分钟`
3. 设置生效时间范围：比如 `09:00 ~ 22:00`
4. 点「＋ 添加提醒」，完成！在时间范围内，每隔 30 分钟奶蛙就会跳出来笑一次

### 小提示

- 点列表里的「测试」可以立刻看一次弹窗效果（含笑声）
- 结束时间设为 `23:59` 基本等于"今天一直提醒"；开始 = 结束视为全天生效
- 提醒弹窗可以叠加，多个提醒同时到点会排成一列

## macOS 从源码构建（部署）

### 环境要求

- macOS 14.0 或更高版本
- Xcode Command Line Tools（自带 `swiftc`）：
  ```bash
  xcode-select --install
  ```

### 一键构建

```bash
git clone <本仓库地址>.git
cd 奶蛙的爱意提醒物语
./build.sh
```

`build.sh` 会自动完成：编译 Swift 源码 → 生成 `.app` 包 → 拷贝图片音效资源 → 生成图标。构建产物为当前目录下的 `奶蛙的爱意提醒物语.app`，双击即可运行。

### 手动构建

```bash
# 编译
swiftc -O -parse-as-library -o naiwa app/NaiwaApp.swift -target arm64-apple-macosx14.0

# 组包
mkdir -p "奶蛙的爱意提醒物语.app/Contents/MacOS" "奶蛙的爱意提醒物语.app/Contents/Resources"
cp naiwa "奶蛙的爱意提醒物语.app/Contents/MacOS/"
cp assets/laugh*.png assets/naiwa_laugh.mp3 "奶蛙的爱意提醒物语.app/Contents/Resources/"
# 再按仓库内 app/Info.plist 模板写入 Info.plist、用 iconutil 生成 AppIcon.icns 即可
```

### 项目结构

```
├── app/
│   └── NaiwaApp.swift      # 全部源码（SwiftUI + AppKit，单文件约 580 行）
├── assets/

│   └── naiwa_laugh.mp3           # 奶蛙笑声
├── naiwa-windows/          # 奶蛙 Windows 版（Python + PySide6）
│   └── README.md           # Windows 奶蛙版使用说明
├── niulai-windows/         # 牛来 Windows 版（Python + PySide6）
│   ├── app/niulai_app.py   # 提醒程序
│   ├── assets/             # 牛来动图、图片、图标和音效
│   ├── run.bat             # 源码启动入口
│   ├── build.ps1           # 打包 Windows EXE
│   └── README.md           # Windows 牛来版使用说明
├── build.sh                # macOS 一键构建脚本
├── LICENSE                 # MIT
└── README.md
```

提醒数据保存在 `~/Library/Application Support/NaiwaReminder/reminders.json`，卸载时删除该目录即可清理干净。
